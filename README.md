# Mehr Iran Dokht — iOS app (Capacitor wrapper)

Native iOS wrapper around the «مهر ایران دخت» web app, built with
[Capacitor 8](https://capacitorjs.com). The web app itself lives in the
`online-shop` web artifact; this repo holds the wrapper only.

## Layout

- `www/` — copy of the web app (`index.html` + `assets/`). Never edit by
  hand: it is refreshed from the live site, then `npx cap sync ios`.
- `capacitor.config.ts` — app ID `ca.elnazmoghadam.mehrirandokht`, name
  «مهر ایران دخت», royal-blue background.
- `ios/` — Xcode project generated by `npx cap add ios` (Capacitor 8,
  deployment target iOS 15). Contains the final calligraphy app icon,
  royal-blue launch screen, and `PrivacyInfo.xcprivacy`.
- `icons-ios/` — full iOS icon set generated from the final v4 icon
  (`icon-1024-calligraphy-v4.png`).
- `codemagic.yaml` — cloud build (macOS runner): builds the signed `.ipa`
  and uploads it to TestFlight. No Mac required.
- `../builder-snippet-native-bridge.md` — two small edits the web artifact
  needs (external links, mailto, `.ics` reminders inside the app).

## Commands (run in this folder)

```bash
npm ci                  # install dependencies
npx cap sync ios        # copy www/ into the Xcode project + update plugins
```

The `.ipa` is built on Codemagic (see `codemagic.yaml`), not on this Linux
machine — Xcode only runs on macOS.

## Version

- App version 1.0 (build 1). Bump `MARKETING_VERSION` /
  `CURRENT_PROJECT_VERSION` in the Xcode project for each new TestFlight
  build.
